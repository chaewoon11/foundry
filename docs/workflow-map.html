2. A briefing

The same shape in stages 1, 2 and 5. Only questions without a correct answer go to the user; derivable choices come as one list.

sequenceDiagram
  autonumber
  participant A as Author agent
  participant O as Orchestrator
  participant U as User
  participant R as REVIEW.md
  A->>O: documents, overview, item list
  O->>U: page with the big picture (no approval)
  O->>U: anything odd or missing?
  loop each user question
    O->>U: question, pointing to its slide
    U->>O: answer
    O->>R: record answer verbatim
  end
  O->>U: agent decisions as one list
  U->>O: approve, or veto single lines
  O->>A: all changes at once
  A->>O: revised documents
  O->>U: re-brief what changed
  U->>O: approve the review
  O->>R: APPROVED (a hook refuses if anything is open)

3. Who may see what

Enforced by a hook on every file and shell call of an agent. The orchestrator is not restricted. Why: if one model writes code and tests from the same reading, one misunderstanding ends up in both and they agree.
